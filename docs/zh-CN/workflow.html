🤝
真实 Agent Teams
[T] 使用 Claude Code 原生 TeamCreate / SendMessage / TeamDelete，verifier 拥有独立 context window，不是角色模拟。
🧪
四层自验证 [V]
Layer 0 CLI 检查 → Layer 1 API/DB 验证 → Layer 2 浏览器 UI → Layer 3 独立验收确认。按任务类型自动选择激活层。
🔀
双模型交叉审查
/ce:review [C][G] 同时调用 Codex 和 Gemini，双方共同发现的问题优先级自动提升，减少漏报。
🎉
派对模式 [P]
[P] 3 核心视角快速验证（用户代言人 + 技术专家 + 魔鬼代言人），[P+] 12-14 专家视角深度发散。两种模式结束后均自动触发探索者+挑战者结构化收敛。
📖
历史经验检索 [R]
执行前自动检索 docs/solutions/ 经验库，相关解决方案注入上下文，避免重复踩坑。
🔒
合约白名单门控
/ce:plan [T] 自动生成 .team-contract.md，/ce:work [T] 强制单写者原则，/ce:review [T] 激活 Patch Gate 验证。

场景指南 — 什么情况用什么命令
🏠
刚打开项目
/ce:resume → 看完摘要后选下一步
🔮
不知道做什么
完全没想法 → /ce:ideate
之前记了一些 → /ce:ideas 选一个
💡
有功能想做
/ce:brainstorm 想清楚 → plan → work → review
📋
需求很清楚
跳过 brainstorm，直接 /ce:plan → work → review
🐛
修 Bug
简单 bug → 直接改 → /ce:review
复杂 bug → brainstorm 分析 → plan → work
📚
沉淀经验
解决了有价值的问题 → /ce:compound 记录到经验库
工具命令
🩺
/ce:doctor
健康检查：检测 CLI、MCP、认证状态，支持一键修复。
🔀
/ce:pr
创建 Pull Request 并询问是否合并到主分支。
🔄
/ce:sync-upstream
检测上游仓库最近 30 天更新，生成智能分析报告。
✏️
Pencil MCP 联动
在 AI 会话中直接读写 .pen 设计文件，生成组件、修改布局、调整变量。无需切换工具，AI 即是设计师。查看详情 →
🔍
Figma 设计对比同步
figma-design-sync 自动截图并与 Figma 设计稿逐项对比，列出视觉偏差，迭代修复直到像素对齐。
🖼️
frontend-design Skill
生成有设计意图的 Web 界面（响应式、深浅色主题），不是 AI 模板堆砌，而是真实质感的 HTML/CSS/JS 实现。
