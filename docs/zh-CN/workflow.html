真实 Agent Teams
[team] 使用 Claude Code 原生 TeamCreate / SendMessage / TeamDelete，verifier 拥有独立 context window，不是角色模拟。
🧪
四层自验证 [T]
Layer 0 CLI 检查 → Layer 1 API/DB 验证 → Layer 2 浏览器 UI → Layer 3 独立验收确认。按任务类型自动选择激活层。
🔀
双模型交叉审查
/ce:review [C][G] 同时调用 Codex 和 Gemini，双方共同发现的问题优先级自动提升，减少漏报。
🎉
派对模式 [P]
14 个专家视角发散讨论（探索者 / 挑战者 / 安全 / 性能 / QA…），结束后自动触发结构化收敛，无需额外参数。
📖
历史经验检索 [R]
执行前自动检索 docs/solutions/ 经验库，相关解决方案注入上下文，避免重复踩坑。
🔒
合约白名单门控
/ce:plan [team] 自动生成 .team-contract.md，/ce:work [team] 强制单写者原则，/ce:review [team] 激活 Patch Gate 验证。
