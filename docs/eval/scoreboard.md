# Eval Scoreboard

> 历史评测得分记录。每次运行 eval 后在此追加结果。

## 评分阈值

| 维度 | Blocking 阈值 | Analytical 阈值 | Advisory 阈值 |
|------|--------------|----------------|--------------|
| FPR (误报率) | ≤ 5% | ≤ 10% | ≤ 25% |
| FNR (漏报率) | ≤ 5% | ≤ 10% | ≤ 20% |
| RSR (恢复率) | ≥ 90% | — | — |
| CCR (合规率) | ≥ 95% | ≥ 95% | ≥ 90% |
| FVR (核查率) | ≥ 95% | ≥ 90% | ≥ 80% |

综合得分公式：`0.35×(1-FNR) + 0.25×(1-FPR) + 0.25×CCR + 0.15×RSR`
通过阈值：≥ 0.80
