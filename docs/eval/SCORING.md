# 评分标准详细说明

## 单案例评分公式

```
总分 = 核心判断 * 0.5 + 合约合规 * 0.2 + 证据质量 * 0.2 + 无噪声 * 0.1
```

### 核心判断（50%）

| 案例类型 | 满分条件 | 零分条件 |
|----------|----------|----------|
| 误报案例（fp-*） | 0 个 FP finding | 任意 1 个 FP finding |
| 漏报案例（fn-*） | 所有预埋问题被发现 | 0 个预埋问题被发现 |
| 恢复案例（rsr-*） | 恢复后 finding 与全量一致率 >= 80% | 一致率 < 50% |
| 合约案例（ccr-*） | 所有字段完整 | 缺失 > 2 个必填字段 |
| 端到端（e2e-*） | 预埋问题检出率 >= 2/3 | 检出率 < 1/3 |

**部分得分规则**：
- 漏报案例：检出 2/3 预埋问题 = 0.67 分
- 恢复案例：一致率 75% = 0.75 分（线性）

### 合约合规（20%）

检查 Structured Finding 的 7 个必填字段：

| 字段 | 权重 | 说明 |
|------|------|------|
| Claim | 1/7 | 具体声明 |
| Type | 1/7 | exists/missing/dead_work/conflicts_with_plan/risk/opinion |
| Scope | 1/7 | component/option/method/file/api |
| Evidence | 1/7 | 含 file:line 引用 |
| Proposed Action | 1/7 | 具体建议 |
| Confidence | 1/7 | high/medium/low |
| Assumptions | 1/7 | 假设说明 |

**额外必填**（type=dead_work/exists/missing 时）：
- Counter-checks 字段：缺失直接扣 0.1

**得分** = 已填字段数 / 应填字段总数

### 证据质量（20%）

| 级别 | 得分 | 标准 |
|------|------|------|
| 精确 | 1.0 | `file:line` + 代码片段，可在源码中定位 |
| 可追溯 | 0.7 | 提到文件名但无行号，或行号不准确 |
| 模糊 | 0.3 | 仅描述性文字，无具体定位 |
| 缺失 | 0.0 | Evidence 字段为空或 N/A |

**得分** = 所有 finding 的证据质量均值

### 无噪声（10%）

**得分** = max(0, 1.0 - 0.1 * 无关_finding_数量)

- 0 个无关 finding → 1.0
- 1 个 → 0.9
- 5 个 → 0.5
- 10+ 个 → 0.0

## 阈值速查

| Tier | FPR 上限 | FNR 上限 | CCR 下限 | FVR 下限 |
|------|----------|----------|----------|----------|
| Blocking | 5% | 5% | 95% | 95% |
| Analytical | 15% | 10% | 95% | 90% |
| Advisory | 25% | 20% | 90% | 85% |
