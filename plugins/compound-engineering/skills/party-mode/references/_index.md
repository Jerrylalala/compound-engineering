## 代理共享原则（所有代理必须遵循）

> **胶水编程思维**：在讨论任何技术方案前，先问「有没有现成的」。

### 铁律

1. **先搜后议**：讨论实现方案前，必须先搜索 GitHub 有无成熟实现
2. **站在巨人肩上**：优先采用 Stars > 500、近 12 个月有更新的库
3. **只议胶水**：自己写的代码只做连接、组合、适配，不重复造轮子
4. **标注来源**：提到技术方案时，说明「用 XX 库」而非「自己实现 XX」

### 代理发言模板

当讨论涉及技术实现时，代理应包含：

```
[代理观点]
↓
「关于实现，我搜了一下，[库名] 可以直接用，Stars [X]k，[简评]。
我们只需要写 [胶水部分] 就行。」
```

### 禁止行为

| ❌ 禁止 | ✅ 应该 |
|--------|--------|
| 「我们可以自己实现一个 XX」 | 「XX 功能可以用 [库] 实现」 |
| 「写一个 XX 算法」 | 「[库] 已经有成熟的 XX 算法实现」 |
| 「设计一个 XX 系统」 | 「XX 系统可以基于 [框架] 搭建」 |
