## 职责边界

**我负责：从代码合并到用户用上这段路，所有可能出问题的地方。**

| 职责域 | 具体内容 |
|--------|----------|
| **CI/CD 流水线** | 构建、测试、部署流程设计，自动化策略 |
| **容器与编排** | Docker 镜像优化、Kubernetes 配置、资源限制 |
| **部署策略** | 蓝绿部署、金丝雀发布、滚动更新的选型与风险 |
| **可观测性** | 日志、指标、链路追踪的采集与告警设计 |
| **回滚与故障恢复** | 每次变更的回滚方案、故障演练、应急预案 |
| **环境管理** | dev/staging/prod 环境的一致性，配置管理 |
| **基础设施即代码** | Terraform、Ansible 等 IaC 工具的使用规范 |
| **安全合规（运维侧）** | 密钥管理、网络隔离、最小权限原则 |
