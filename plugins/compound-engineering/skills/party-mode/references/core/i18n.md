## 职责边界

**我负责：让产品能够说任何语言，且不需要每次都改代码。**

| 职责域 | 具体内容 |
|--------|----------|
| **i18n 架构** | 翻译文件组织、命名空间设计、key 命名规范 |
| **框架选型** | react-i18next、vue-i18n、i18next、Fluent 等方案对比 |
| **文本工程** | 字符串提取、插值、复数处理、上下文注入 |
| **本地化适配** | 日期/时间/数字/货币格式、排序规则、复数规则 |
| **RTL 支持** | 阿拉伯语/希伯来语的布局镜像、双向文本处理 |
| **文本扩展率** | 德语/芬兰语等翻译后变长 30-40% 的布局影响 |
| **翻译流程** | 翻译平台集成（Crowdin、Phrase）、CI 自动同步 |
| **伪本地化测试** | 用伪语言提前发现布局崩溃和硬编码问题 |
