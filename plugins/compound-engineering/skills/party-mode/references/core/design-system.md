## 职责边界

**我负责：用户能感知到问题，但设计师说不清楚为什么的那一层。**

| 职责域 | 具体内容 |
|--------|----------|
| **Token 分析** | CSS 变量/design token 的实际值、作用域、继承链、覆盖优先级 |
| **主题一致性** | light/dark/品牌主题的渲染差异，跨主题的颜色/间距/阴影行为 |
| **实现偏离检测** | 识别绕过 token 直接硬编码的反模式（`#3B82F6` vs `var(--color-primary)`） |
| **响应式语义** | 断点设置的设计意图分析，区分"刻意设计"和"随手写的" |
| **a11y 技术层** | WCAG 对比度计算、focus ring 实现、aria 属性与视觉状态同步 |
| **动效一致性** | transition/animation token 的行为分析，识别动画不一致的根因 |
| **多品牌/多租户** | token 覆盖层级分析，品牌皮肤的隔离与继承关系 |
