# 保存项目上下文

在会话结束前，生成并保存完整的项目上下文文档，用于下次会话恢复。

## 默认保存位置

```
docs/context/project-context.md
```

## 使用方式

```bash
/workflows:save                           # 保存到默认位置
/workflows:save docs/context/v2.md        # 保存到指定位置
```

## 参数

<save_path> #$ARGUMENTS </save_path>

如果未指定路径，默认保存到 `docs/context/project-context.md`

---

## 执行流程

### Step 1: 确定保存路径

```
如果 <save_path> 不为空:
    保存路径 = <save_path>
否则:
    保存路径 = "docs/context/project-context.md"
```

### Step 2: 确保目录存在

```bash
mkdir -p docs/context
```

### Step 3: 生成项目上下文文档

基于**当前对话中的全部已知信息**，生成结构化的项目上下文文档。

**重要规则**：
- 若某字段在当前对话中**未明确出现或无法合理推断**，填写为"暂无信息"
- 不得自行虚构事实
- 输出内容必须结构稳定、层级清晰

### Step 4: 写入文件

将生成的文档写入保存路径。

## 完成输出

保存成功后，输出：

```

📅 更新时间: {当前时间}
📝 会话摘要: {一句话概括}

下次开启新会话时，使用以下命令恢复：
  /workflows:load

或手动粘贴该文件内容到新会话中。
```

---

## 适用场景

- 长对话即将结束，需要保存工作状态
- 准备切换到其他项目，稍后返回
- 需要将当前进展分享给团队成员
- 跨设备继续工作

## 相关命令

- `/workflows:load` - 加载项目上下文，恢复会话
- `/workflows:compound` - 记录已解决的问题（不同用途）
