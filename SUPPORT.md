# Support

Use the right channel for the kind of help you need.

## Bugs

Open a bug report with the GitHub issue template. Include:

- operating system and shell
- Claude Code, Codex, Gemini, or other target tool version
- package or plugin version
- exact command you ran
- expected result
- actual result
- relevant logs or screenshots

## Feature Requests

Open a feature request with:

- the workflow you are trying to improve
- the target platform affected
- why the current behavior is not enough
- any compatibility constraints

## Security Issues

Do not open a public issue for undisclosed vulnerabilities. Follow [SECURITY.md](SECURITY.md).

## Maintenance Expectations

This is an open-source project maintained as time allows. Issues with clear reproduction steps, current versions, and validation evidence are easier to triage and fix.
